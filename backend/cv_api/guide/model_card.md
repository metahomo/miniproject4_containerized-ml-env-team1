# 모델 카드 (FR-18)

## 목적
대전 대중교통(시내버스 차내, 도시철도 승강장) 관제 영상 프레임에서 사람을 비식별로 검출해, 관심영역(ROI) 안의 인원을 세고 차량 전체 정원 대비 혼잡도(%)·잔여 탑승 가능 비율(%)·혼잡 등급을 추정한다.

## 검출 모델
- **운영 중 (2026-09-29 17:20~): 머리(head) 검출 가중치 `head_crowdhuman_n1280.pt`.** YOLOv8n 에서 출발해 공개 데이터 CrowdHuman(검증 묶음 4,370장)으로 머리 1클래스를 추가 학습한 1차 모델(26에폭, mAP50 0.787). 차내 만원에서 몸·발이 가려지는 문제 때문에 머리를 센다. 가중치의 클래스 이름이 `head` 라 자동으로 머리 모드(`MODEL_TARGET=auto`). 학습 절차는 `scripts/train/README.md`.
  - CrowdHuman 시험 사진 429장(평균 22명): 한 장당 인원 오차 **4.91명**(이전 몸 검출 기준 0.4 에서 9.99명), SC-01(정원 80 가정) 86.5%.
  - **차내 영상에서는 아직 검증되지 않았다.** 차내 샘플 영상에서는 이전 모델과 비슷하거나 적게 세는 장면이 있었다(뒤통수·카메라 가까운 큰 머리). 대전 차내 CCTV 로 2차 학습 예정(T094).
  - 라이선스: YOLOv8 AGPL-3.0 + CrowdHuman CC BY-NC 4.0(비상업) — **운영 사용 가부는 발주 측 확인 전**이다.
- 이전 모델: `yolov8n.pt` (Ultralytics 배포본, person 클래스, 출처 `https://github.com/MaxTheTechy/yolo` 의 접근법 — 저장소에 라이선스 파일 없음). 설정 한 줄로 되돌릴 수 있다.
- 진단 기록의 모델 판본(`model_package`)은 실제로 적재한 가중치 파일의 해시로 남는다.
- 입력 크기: 사진을 긴 변 1280px 로 맞춰 검출한다(`MODEL_IMGSZ`, 2026-09-29 — 640 보다 작고 먼 사람을 더 잡는다. 역 대합실 밀집 샘플 평균 5.4 → 12.8명, 한 장 약 65ms).
- 대안 백엔드: 공유 Ollama 서버의 비전 모델(`gemma4:e4b`)로 사람 박스를 JSON 으로 받는 어댑터. 파일럿 비교용.

## 계산 (서비스가 보장하는 계약)
- 검출 신뢰도가 인원 세기 기준(머리 모델 0.2 — 평가 최적값, 몸 검출 모델은 0.4. 운영 관리자가 S3 에서 조정) 이상이고 기준점이 ROI 안인 사람만 센다 → `person_count`. 기준점은 몸 검출이면 박스 아래 중앙점(발 위치), 머리 검출이면 박스 중심이다. 모델을 바꾸면 인원 세기 기준을 `scripts/train/eval_count.py` 로 다시 정한다.
- `occupied_area_ratio = person_count ÷ 차량 전체 정원 × 100`(100 상한, 넘으면 `over_capacity`), `vacant_capacity_ratio = 100 − occupied`. 정원이 없으면 인원만 내고 혼잡도는 산출 불가(판독 불확실).
- 평균 신뢰도(기준 0.6)는 셈에 든 사람만으로 계산한다. 차량 합산은 카메라별 인원 합 ÷ 정원 (research R22, 2026-09-29).
- 등급은 운영 관리자가 조정하는 경계값(기본 여유 ≥ 50%, 혼잡 < 20%)으로 매핑한다.

## 한계
- 완전히 가려진 사람은 검출되지 않아 만원 구간에서 과소 계측될 수 있다(`occlusion` 경고).
- 카메라 각도·조도·흔들림에 따라 검출률이 달라진다. 기준 미달 시 확정값 대신 `uncertain` 을 낸다.
- 차량 전체 정원이 등록되지 않은 카메라는 인원만 내고 혼잡도는 산출 불가(`unknown` 경고 "정원 미등록")로 표시한다.
- 밀집 군중(사람이 겹쳐 머리만 보이는 장면)에서는 인원을 크게 적게 센다 — 역 대합실 샘플(실제 약 100명 이상)에서 몸 검출 27명, 머리 검출 39명(2026-09-29, 정답 없는 샘플).
- 주간 통근 시간대 기준으로 정한 임계값이 심야·특수 기상에서 어긋날 수 있다. 시간대·조도별 신뢰도 편차를 운영 지표로 기록한다.

## 면책
모든 수치는 통계적 추정치이며 실제 탑승 가능 여부·안전을 보장하지 않는다. 개인 식별 정보는 생성·저장·전송되지 않는다.

## 검증 결과
파일럿(정확도 검증 S4) 결과를 여기에 기록한다. 목표: 잔여 비율 ±10%p 이내 일치 85%, 등급 일치 85%(SC-01·02). 현재: 미실시.
