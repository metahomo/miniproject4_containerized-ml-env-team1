01 · 원칙

여덟 가지 핵심 특성

Apple 웹의 다섯 페이지(홈·환경·스토어·iPhone 구매·액세서리)를 분석해 얻은 규칙이다. 이 프로젝트의 시연 웹과 관리자 화면은 같은 규칙을 다른 볼륨으로 쓴다.

사진 우선

UI는 뒤로 물러나고 콘텐츠(이 프로젝트에서는 진단 결과 숫자)가 앞에 선다.

색으로 나눈 구간

흰색·양피지색과 near-black 타일이 교대한다. 선이나 그림자 대신 배경색 변화가 구분선이다.

단 하나의 파란색

모든 상호작용 요소는 --color-primary #0066cc. 두 번째 브랜드 색은 없다.

두 가지 버튼 문법

행동은 pill(완전 둥근 캡슐), 유틸리티는 8px 직각. 그 사이 값은 쓰지 않는다.

타이트한 헤드라인

Display 크기에 음수 letter-spacing. 나눔바른고딕 Bold(700) 하나로 헤드라인을 세운다.

그림자는 하나

시스템 전체에서 유일한 그림자는 제품 이미지 아래. 카드·버튼·글자에는 절대 없다.

두 줄 내비게이션

44px 검정 global-nav + 52px 반투명 sub-nav. 우측에 항상 주요 행동 버튼.

예측 가능한 리듬

밝은 히어로 → 어두운 타일 → 밝은 유틸리티 → 어두운 타일 → 양피지 푸터.

03 · 타이포그래피

글자 위계

모든 글자는 나눔바른고딕 하나로 통일한다. 네이버 웹폰트 CSS 로 불러오며 Light 300 · Regular 400 · Bold 700 세 굵기를 제공한다. Apple 원본의 600 은 700 으로 매핑했다. 500 은 쓰지 않는다.

원칙

  • 17px 이상 헤드라인은 음수 자간. 12px 이하에서는 쓰지 않는다.
  • 본문은 17px. 16px 이 아니다.
  • 헤드라인 굵기는 700. 나눔바른고딕에 600 이 없어 Apple 의 600 을 700 으로 매핑했다.
  • 본문 행간 1.47 아래로 줄이지 않는다.

글꼴 로드

  • 네이버 배포 woff 를 @font-face 로 300 / 400 / 700 세 굵기를 NanumBarunGothic 한 이름에 묶었다. 네이버 기본 CSS 는 굵기마다 이름이 달라 그대로 쓰면 굵기가 합성된다.
  • 스택 뒤에 system-ui 를 두어 오프라인에서도 깨지지 않게 한다.
  • 오프라인 시연이면 폰트 파일을 로컬에 두고 @font-face 로 바꾼다.

07 · Do / Don't

지킬 것과 피할 것

Do

  • 모든 상호작용 요소에 --color-primary 하나만 쓴다.
  • 헤드라인은 hero-display / display-lg, 700, 음수 자간.
  • 본문은 17px / 400 / 1.47.
  • 구간은 밝은 타일과 어두운 타일을 교대해 나눈다.
  • pill 은 행동에만. 칩, 검색, 고정 바 CTA 포함.
  • 그림자는 제품 이미지에만.
  • 모든 버튼 눌림은 scale(0.95).
  • global-nav 는 순수 검정. 페이지에서 검정이 나오는 유일한 곳.
  • 혼잡 상태 색은 정보 표시에만 쓴다.

Don't

  • 두 번째 액센트 색을 만들지 않는다. 상태 색을 버튼에 쓰지 않는다.
  • 카드·버튼·글자에 그림자를 넣지 않는다.
  • 장식용 그라디언트 배경을 쓰지 않는다.
  • 굵기 500·600 을 쓰지 않는다. 나눔바른고딕 사다리는 300 / 400 / 700.
  • 타일 모서리를 둥글게 하지 않는다.
  • 본문 행간을 1.47 아래로 줄이지 않는다.
  • 모서리 문법을 섞지 않는다. sm / lg / pill 외에는 Pearl 의 md 만.
  • Sky Blue 를 밝은 배경에 쓰지 않는다.
  • Hover 상태를 문서화하지 않는다.

08 · 반응형

브레이크포인트

구조적으로 중요한 지점은 1440(콘텐츠 잠금), 1068, 833, 734, 640, 480. 터치 타깃 최소 44 × 44px.

Phone420–640단일 열. 히어로 34px. 제품 이미지 타일 폭의 80%
Large phone641–735타일 수직 여백 80 → 48px

Tablet landscape834–1023global-nav 복원. 3열 → 2열

Desktop1069–1440전체 레이아웃. 4~5열 그리드
