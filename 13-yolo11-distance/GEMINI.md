# 작업 및 실행 규칙 (Rules)

## 1. 기본 원칙 (사전 확인 후 실행)
- 코드 수정(`edit_file`, `write_file`)이나 터미널 명령어 실행(`run_command`)이 필요한 경우, **기본적으로 도구를 바로 실행하지 않는다.**
- 반드시 사전에 **수정 계획, 변경될 코드(diff 또는 코드 스니펫), 또는 실행할 명령어**를 사용자에게 먼저 보여주고 진행 여부를 확인받는다.
- 사용자가 "진행해", "수정해", "실행해", "확인했어" 등으로 승인한 후에 실제 도구를 호출한다.

## 2. 예외 규칙 (즉시 실행)
- 사용자의 프롬프트에 **즉각적인 실행을 지시하는 표현**이 포함된 경우에는 사전 확인 절차 없이 즉시 파일을 수정하거나 명령어를 실행한다:
  - 예: *"묻지 말고"*, *"묻지말고 해줘"*, *"바로 수정해줘"*, *"직접 실행해줘"*, *"알아서 고쳐줘"*, *"즉시 반영해"* 등
