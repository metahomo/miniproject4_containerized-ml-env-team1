1. 개요 및 긴급 개선 배경

기존에 적용된 일반 객체 탐지 모델(COCO 데이터셋 기반 YOLO11 및 일반 CrowdHuman 모델)을 활용하여 만원 버스 승객 이미지(bus_full.jpg)를 분석한 결과, 실제 15명 이상의 승객이 밀집해 있음에도 불구하고 불과 7명만 검출되어 최종 혼잡도가 여유 (EMPTY)로 심각하게 오판정되는 현상이 확인되었습니다.

⚠️ 미검출(False Negative) 발생 원인:
1. 도메인 격차(Domain Gap): 버스 내부는 카메라와 승객 간 거리가 가깝고 손잡이, 의자 등 구조물에 의한 머리 및 신체 가림(Occlusion)이 심하게 발생함.
2. 입력 해상도 불일치: 1280 해상도로 사전학습된 두부 특화 모델(head_crowdhuman_n1280.pt)에 기본 640 해상도로 축소 입력되어 소형/원거리 두부 특징이 소실됨.
3. 신뢰도(Confidence) 임계값 과다: 기본 신뢰도(0.20~0.25)가 엄격하여 가려지거나 흐릿한 승객 객체가 일괄 탈락됨.

2. 긴급 파라미터 최적화 조치 및 성능 검증

모델 재학습 전에 모델의 구조적 파라미터를 즉시 튜닝하여 미검출 현상을 개선하였습니다. src/dual_pipeline.py와 scripts/test_dual_vacancy.py에 정밀 매개변수 제어 구조를 적용하였습니다.

3. 버스 객실 맞춤형 5단계 추가 학습(Fine-tuning) 인프라 구축

파라미터 튜닝만으로는 해결하기 어려운 극단적 가림(Occlusion)과 버스 특유의 역광·시야각 문제를 완벽하게 극복하기 위해 실제 버스 환경 데이터로 전이학습(Transfer Learning)을 수행할 수 있는 5단계 인프라를 구축 완료했습니다.

1단계 차내 특화 라벨링 규격

• 수집 권장: 500~1,000장 (출퇴근 혼잡, 야간, 역광 등)
• Class 0 (head): 가려진 머리, 모자, 측면/후면 두부
• Class 1 (person): 착석 승객, 겹쳐진 전신/상반신

2단계 데이터셋 구조 & 분할 도구

• datasets/bus_crowd/images/train, val
• datasets/bus_crowd/labels/train, val
• scripts/split_bus_dataset.py 구축 완료
(수집 데이터 8:2 자동 분할 배치)

3단계 훈련 설정 메타데이터

• 파일: datasets/bus_crowd/data.yaml
• YOLO 표준 경로 및 2개 특화 클래스 정의 완료
• Ultralytics 표준 연동 테스트 완료

4단계 이중 모델 파인튜닝 스크립트

• 파일: scripts/train_bus.py
• CUDA GPU / CPU 디바이스 자동 감지
• 데이터셋 사전 검증(Pre-check) 및 안전 종료 구현
• Model A (1280) & Model B (640) 순차 훈련 지원

5단계 최적 가중치 자동 배포 파이프라인

학습 완료 후 생성된 best.pt 가중치를 공식 백엔드 모델 디렉터리(backend/models/)로 즉시 덮어쓰기 배포할 수 있는 --deploy 자동화 옵션을 탑재하였습니다. 

# 5단계 파이프라인 전체 실행 명령어 예시:
# 1) 수집된 데이터 8:2 분할 배치
python scripts/split_bus_dataset.py --src-dir ./raw_bus_images --dest-dir datasets/bus_crowd

# 2) 버스 맞춤형 추가 학습 실행 (50 에포크, 완료 후 공식 가중치 자동 교체)
python scripts/train_bus.py --epochs 50 --deploy

# 3) 융합 파이프라인 최종 검증
python scripts/test_dual_vacancy.py --source ../backend/samples/bus_full.jpg --out results/dual_full_final.jpg
