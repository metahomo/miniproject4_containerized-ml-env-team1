시점인원밀집도등급응답
이 페이지는 외부 웹서비스가 혼잡도 진단 API 를 연계해 쓰는 모습을 보여 주는 시연이다. 브라우저는 이 서비스의 서버(/partner-api)에 프레임만 보내고, 서버가 승인된 API 키를 붙여 https://p4.sumzip.com/model-api/v1/diagnose 로 전달한다 — 키는 브라우저에 오지 않는다. 이 서비스에 배정된 카메라는 CAM-PARTNER-01(관심영역 = 화면 전체)이고, 밀집도는 그 카메라에 등록된 정원 기준이다. 모든 수치는 통계적 추정치이며, 판단보류는 화질·신뢰도가 기준에 못 미쳐 «참고용»이라는 뜻이다.
